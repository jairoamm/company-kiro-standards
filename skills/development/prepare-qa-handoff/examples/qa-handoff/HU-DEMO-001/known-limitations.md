# Limitaciones conocidas

- El ejemplo usa un ambiente sintético y no concede autorización de ejecución.
- `BASE_URL` debe provenir de la evidencia del pipeline aprobada para el proyecto consumidor.
- CP-004 solo cubre el rechazo visible de credenciales inválidas.
- El paquete no afirma que existan identidades o estados persistidos en un backend.
- La equivalencia con producción no está evaluada en este ejemplo.
